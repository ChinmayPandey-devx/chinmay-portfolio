Amazon Prime Retention Drop

Investigating a gradual 5% decline in user retention (4/7-day) on Prime Video.

View Causal Diagram
Drop in 4-day and 7-day user retention on Amazon Prime.
Users are searching for movies but dropping off after viewing search results.
The movies they searched for were marked with a "Rent" label.
Users did not want to pay extra for movies when they already pay for a Prime subscription.
Root Cause: The introduction of the new rental business model alienated existing Prime subscribers.
Recommendation Shipped: Adjust UI to clearly separate Prime-included content from Rental content, preventing bait-and-switch frustration. Expected to recover retention by 3.5%.

Uber Cancellations Surge

Analyzing a 5% increase in user cancellations post-booking for Uber Go in India.

View Causal Diagram
User cancellations for Uber Go increased by 5% gradually over 3 months.
Cancellations occur after the ride is booked and after the user speaks to the driver.
Drivers are calling users to negotiate ride terms.
Drivers are asking users to pay extra for tolls or take the ride offline to avoid commission.
Root Cause: Drivers are dissatisfied with fare margins and toll handling, pushing them to offline solicitation.
Fix Shipped: Include toll/parking charges directly into upfront fares with clear driver bifurcation, and penalize offline-ride solicitation while adding milestone rewards.

Google Maps DAU Drop

Investigating a sudden 10% global drop in Daily Active Users on Google Maps.

View Causal Diagram
Global 10% drop in DAUs seeking navigation over the past week.
Users open the app and type in a search, but drop off immediately.
The search results are taking too long to load (latency spikes).
The mapping index is failing to return rapid queries, causing timeouts.
Root Cause: Search index degradation / high-resolution image loads causing critical latency, leading to user abandonment.
Fix Shipped: Rollback recent infrastructure changes to map rendering and optimize search index query times to restore sub-second load.
